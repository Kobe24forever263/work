# 阶段12观测与动作归一化规格

## 固定形状

- 观测：`float32[282]`
- 候选动作特征：`float32[1536, 16]`
- 动作掩码：`bool[1536]`
- 任务槽位：8
- 机器人槽位：10，按机器人 ID 排序
- 楼梯槽位：4，按楼梯 ID 排序

## 全局状态（6维）

| 字段 | 归一化 |
|---|---|
| 当前时间 | `now / time_limit` |
| 等待任务数 | `/ 50` |
| 尚未到达任务数 | `/ 50` |
| 已完成数 | `/ task_limit` |
| 失败数 | `/ task_limit` |
| 决策间隔 | `/ 10 s` |

## 单任务状态（每槽13维）

依次为：有效位、起点楼层 `/2`、目标楼层 `/2`、是否跨层、优先级 `/3`、
等待时间 `/600 s`、剩余截止时间 `/600 s`、起点 `x/25,y/25,z/5`、
目标点 `x/25,y/25,z/5`。空槽全部补零，并由有效位区分真实零值。

## 单机器人状态（每槽14维）

依次为：有效位、是否 Go2、名义速度 `/2.0 m/s`、楼层 `/2`、可用、故障、带货、已有任务、
位置 `x/25,y/25,z/5`、累计距离 `/1000 m`、累计任务 `/50`、
连续空闲时间 `/600 s`。布尔量使用0/1。

## 单楼梯状态（每槽8维）

依次为：有效位、是否空闲、一楼端点 `x/25,y/25,z/5`、二楼端点
`x/25,y/25,z/5`。

## 单候选动作特征（16维）

依次为：有效位、三种运输模式 one-hot（`SINGLE_CAR`、`SINGLE_DOG`、
`CAR_DOG_CAR`）、任务槽、取货车槽、Go2槽、楼梯槽、接货车槽、是否跨层、
取货车到起点 ETA `/100 s`、Go2接近 ETA `/100 s`、取货侧 ETA `/200 s`、
楼梯 ETA `/100 s`、目标侧 ETA `/200 s`、总估计时间 `/300 s`。

## 约束

- 训练和推理必须使用完全相同的 ID 排序与缩放常数；
- padding 动作的 mask 必须为 false；
- 无合法候选时，仅索引0表示受控 `WAIT`；
- 网络输出在采样前必须应用动作掩码；
- 如实际量超过当前尺度，第一版允许大于1，不做静默裁剪，日志必须报警；
- 修改任何缩放常数或字段顺序必须提升编码版本并重新生成训练样本。
- Carter名义速度固定为2.0m/s，Go2名义速度固定为0.8m/s；候选代价必须使用时间而不是裸距离。
- 不存在车—车交接动作；任何 `CAR_CAR_HANDOVER` 输入均为非法动作。
