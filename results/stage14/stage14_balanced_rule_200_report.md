# 阶段14第一轮门禁报告：50%跨层课程与训练接口

## 结论

阶段14第一轮门禁通过。新的Gymnasium训练接口能够复现规则基线；任务分布已从30%
跨层调整为50%跨层，并为单狗与车—狗—车同时提供明确的优势样本。接入P95交接超时
后，200个任务全部进入明确结果，其中成功196、受控失败4；四次失败均为
`HANDOVER_TIMEOUT`。本轮仅验收训练接口和课程数据，不代表强化学习策略已训练完成。

## 任务与模式分布

10个随机种子共运行10个episode、处理200个任务：

| 类别 | 次数 |
|---|---:|
| 同层任务 | 100 |
| 跨层任务 | 100 |
| 单车执行 | 100 |
| 车—狗—车执行 | 70 |
| 单狗执行 | 30 |
| 成功 | 196 |
| P95交接超时失败 | 4 |

每个20任务episode固定包含10个同层任务和10个跨层任务。10个跨层任务中，7个使用
一般货物平台几何，使车—狗—车更高效；3个使用靠近楼梯的平台几何，使单狗更高效。
规则调度器没有被预先指定模式，而是依据相同ETA和奖励逻辑自然得到`10/7/3`分布。

## 训练接口

- 环境：标准Gymnasium事件驱动接口；
- 状态张量：`282`维；
- 候选动作特征：`1536 × 16`；
- 动作掩码：`1536`维；
- 运输模式：`SINGLE_CAR`、`SINGLE_DOG`、`CAR_DOG_CAR`；
- 车—车交接继续禁止；
- 候选动作特征随状态一起提供，策略不需要记忆不稳定的动作编号；
- 没有待执行任务时只开放`WAIT`，本轮共产生124次合法等待决策。
